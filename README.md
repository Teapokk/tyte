# 🚀 TYTE — Termux Your Text Editor

> An advanced, lightweight, and custom-tailored text editor for the Bash / Termux terminal.

**TYTE** is a text editor built specifically to run smoothly right inside the Android terminal using Termux. It brings syntax highlighting, clean line navigation, buffer management, and automatic backups.

---

## 📸 Features

- 🎨 **Dark Navy Theme (TrueColor RGB):** Modern, eye-friendly layout with highlighted line numbers.
- 🧹 **Zero Bloat:** Runs using pure Bash, `sed`, `curl`, and standard system utilities.
- 💾 **Automatic Backups:** Generates a safety copy (`.bak`) before saving modifications.
- 🔄 **Built-in Auto-Update:** Checks for and pulls updates straight from the repository.
- ⚡ **Speed & Simplicity:** Fast and responsive without the complexity of traditional editors.
